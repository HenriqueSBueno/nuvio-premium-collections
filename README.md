# Nuvio Premium Collections

Static collection set for Nuvio with one design and two versions. No GIFs, no generated art.

| Version | Import URL |
| --- | --- |
| Color | `https://cdn.jsdelivr.net/gh/HenriqueSBueno/nuvio-premium-collections@v1/nuvio-premium-color.json` |
| Monochrome | `https://cdn.jsdelivr.net/gh/HenriqueSBueno/nuvio-premium-collections@v1/nuvio-premium-mono.json` |

Both versions use the same collection IDs, so importing one replaces the other. Collections with other IDs are kept.

Requires an AIOMetadata install that has the referenced catalogs.

Film and series images and logos belong to their respective rights holders.
